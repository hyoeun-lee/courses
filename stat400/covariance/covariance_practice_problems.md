# STAT 400 -- Covariance, Variance, Correlation: Practice Problems

Companion to `covariance_demo.Rmd`. Problems that use simulation can be answered with the code from the corresponding section of the demo.

1. If $\mathrm{Var}(X)=4$, $\mathrm{Var}(Y)=9$, $\mathrm{Cov}(X,Y)=3$, find $\mathrm{Var}(X+Y)$, $\mathrm{Var}(X-Y)$ and $\rho$. (Answers: 19, 7, 0.5)
2. In the commute experiment, change the rain probability to 0.1 and 0.5. Which gives the larger covariance between bus and walk? (Use $\mathrm{Var}(R)=p(1-p)$, then check by simulation.)
3. Create two variables that are dependent but have correlation near 0 other than $Y=|X|$.
4. Two independent stocks each have SD \$10. What is the SD of their sum if the correlation is 0? $+0.8$? $-0.8$? (14.1, 19.0, 6.3)
5. Using the dice, compute $\mathrm{Cov}(D_1, \min(D_1,D_2))$ and explain its sign.
